# Web-Scrapping
E-Commerce Data Automation & Web Scraping System (Python, Selenium, BeautifulSoup, Pandas)

Developed an automated data extraction pipeline using Selenium and BeautifulSoup to collect product information from dynamic e-commerce websites.
Implemented browser automation with undetected-chromedriver to handle anti-bot restrictions and dynamically loaded content.
Automated page scrolling, HTML extraction, data parsing, and dataset creation using Pandas for downstream analysis.
Built reusable scraping workflows for collecting product details, pricing information, ratings, and customer review data.
